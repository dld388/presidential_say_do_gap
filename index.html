Do Presidents Govern As They Speak?

Author: David Lopez

Course: DS-GA 1015 - Text As Data

Abstract

This project compares what U.S. presidents say publicly with what they do through formal presidential action. The project builds separate Say and Do corpora, maps each president into an ideological space, and measures the distance between rhetoric and action as a presidential say-do gap.

Project Files

  • Final PDF Report
  • Jupyter Notebook
  • README First

Data Files

The repository includes the chunked presidential corpora used for the analysis, including executive orders, interviews, inaugural addresses, and news conferences.

How to Replicate

  2. Open the README_FIRST file.
